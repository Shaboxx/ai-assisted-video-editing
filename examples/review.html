Review checklist

Watch the preview with audio. Check each source interval, transitions, timing, and retained content. Approve only after reviewing; an approval is tied to the proposal, preview, and original media hashes. Run these commands from the same project directory as the original demo command.

PowerShell

python -m video_edit approve --workdir 'output' --reviewer "Your name" --note "Reviewed timing and content"

python -m video_edit export --workdir 'output'

Bash
